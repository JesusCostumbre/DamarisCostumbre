# 💼 Damaris Costumbre — Sitio Web Profesional

Landing page institucional y de conversión diseñada para **Damaris Costumbre**, Licenciada en Economía (UABJO) y Agente Certificada ante la CNSF con respaldo de Allianz México.

El sitio está estructurado para presentar de manera clara soluciones de ahorro, inversión, retiro deducible (PPR) y blindaje patrimonial, integrando canales directos de captación de prospectos.

---

## 🚀 Características Principales

- **Diseño Mobile-First & Responsivo:** Adaptado con *Media Queries* fluidas para teléfonos móviles, tablets y monitores de escritorio.
- **Optimización SEO Técnico:**
  - Marcado semántico completo con HTML5.
  - Metaetiquetas Open Graph (Facebook/WhatsApp/LinkedIn) y Twitter Cards.
  - Datos estructurados **JSON-LD (Schema.org / `FinancialService`)** para mejorar la indexación en Google.
- **Arquitectura de Conversión (CRO):**
  - Botones de acción directa con preselección automática de servicios en el formulario.
  - Integración nativa a **WhatsApp** con mensajes dinámicos preconfigurados.
  - Botón flotante accesible para contacto rápido.
  - Cumplimiento normativo mediante modal emergente de Aviso de Privacidad.
- **Sin Dependencias Pesadas:** Desarrollado 100% en *Vanilla JavaScript*, CSS moderno (Variables nativas, CSS Grid y Flexbox) y tipografías optimizadas de Google Fonts.
